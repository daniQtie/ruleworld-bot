# Hook Rotation

Purpose: keep video openers varied. Each new video uses the NEXT hook in the cycle, never the same hook twice in a row. After hook 10, loop back to hook 1.

## How to use

1. Check which hook number was used in the previous video.
2. Use the next number in the sequence. If the last one was 10, go back to 1. If no previous video is known, ask the user which number was last used (or start at 1).
3. Write the opener in the style of that hook, matched to the video's topic.
4. State which hook number you used so the next video can continue the cycle.

## The 10 hooks (fixed order)

1. **The "What If" Hook** — poses a surprising hypothetical.
   - "What if I told you na mali lahat ng alam mo tungkol dito?"
   - "What if you could finish this in 5 minutes?"

2. **The Listicle / Number Hook** — promises a set number of points.
   - "These are the 5 steps to ___."
   - "3 mistakes na ginagawa mo without knowing."

3. **The Curiosity / Shock Hook** — withholds info to create intrigue.
   - "This will blow your mind."
   - "Nobody talks about this, pero..."

4. **The Problem-Agitate Hook** — names a pain point.
   - "Are you still doing this? Stop."
   - "If you struggle with ___, watch this."

5. **The Bold Statement / Controversial Hook** — a strong, polarizing claim.
   - "Stop wasting money on ___."
   - "Everything you learned about ___ is wrong."

6. **The Question Hook** — opens with a direct question.
   - "Ever wondered why ___?"
   - "Why do people ___?"

7. **The "Before You..." Hook** — warns before an action.
   - "Before you buy ___, watch this."
   - "Don't start ___ until you see this."

8. **The Story / Personal Hook** — opens with a personal narrative.
   - "I lost everything, then I found this."
   - "6 months ago, I was broke. Now..."

9. **The "Secret / Nobody Tells You" Hook** — promises hidden knowledge.
   - "The secret nobody tells you about ___."
   - "Here's what they don't want you to know."

10. **The Fast-Result / Time Hook** — promises a quick outcome.
    - "How to ___ in 30 seconds."
    - "Learn this in under a minute."

After 10, the next video returns to hook 1.
