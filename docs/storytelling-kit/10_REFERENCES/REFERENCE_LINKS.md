## Competitor research method

For each new reference video, record:
- Exact title and URL.
- Publication date.
- Date of view-count check.
- Public view count and duration.
- The first 3 seconds (observed only if actually watched).
- Actual story premise and progression (observed only if actually watched).
- What is fact versus interpretation.

Public views do not reveal retention, swipe-away rate or private channel analytics.
