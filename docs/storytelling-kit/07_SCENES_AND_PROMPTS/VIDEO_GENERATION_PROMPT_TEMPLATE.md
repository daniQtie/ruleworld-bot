# Provider-Agnostic Video Model Prompt Template

Use this template with the currently configured video-generation provider. Do not assume any specific video provider, model, or MCP is connected.

## Character identity
Paste the exact relevant character-bible description and attach approved reference images if the provider supports image references.

## Visual action
Describe one clear visible action. Specify who does it, what changes, and what the viewer must notice.

## Acting direction
Describe face, gaze, head movement, hands and body language. Avoid vague words such as “emotional” without explaining the visible behavior.

## Camera direction
Specify framing (close-up, medium, wide), angle, movement, focus target and whether the camera cuts or stays continuous.

## Environment and light
Specify location layout, props, time of day, color palette, key light and atmosphere.

## Continuity locks
Repeat required face, hairstyle, clothes, color and environment details. State what must not change.

## Negative constraints
No extra characters, no costume changes, no duplicate limbs, no face redesign, no unexplained props, no text/logos/watermarks, no unrelated actions, no copied competitor assets.

## Final instruction
Generate only the specified shot. Do not invent new plot events. Match the scene's purpose in the approved storyboard.
