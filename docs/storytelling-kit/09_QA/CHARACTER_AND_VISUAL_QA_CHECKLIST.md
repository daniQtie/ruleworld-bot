# Character and Visual QA Checklist

- [ ] Face shape and proportions match the reference.
- [ ] Eye spacing, shape and size remain consistent.
- [ ] Hairstyle and color remain consistent.
- [ ] Clothing and accessories remain consistent.
- [ ] Skin tone and body proportions remain consistent.
- [ ] The correct character appears in the correct scene.
- [ ] Facial expression matches the emotion.
- [ ] Gaze direction points toward the relevant person/object.
- [ ] No unintended extra characters or props.
- [ ] No major visual artifacts, deformed faces or inconsistent limbs.
- [ ] Character scale and environment geography are coherent.
- [ ] Main action is visible in vertical framing.
- [ ] Scene matches the spoken narration.
- [ ] Generated text is not garbled; add precise text in post if needed.
