# Voice QA Checklist

- [ ] Same configured narrator voice ID.
- [ ] Same model ID and accent.
- [ ] Same baseline pitch/timbre and documented stability settings.
- [ ] No random speaker changes between scenes.
- [ ] Emotion matches the scene.
- [ ] Pacing is understandable and not rushed.
- [ ] Pauses sound intentional, not robotic.
- [ ] Pronunciation is correct.
- [ ] No spoken stage directions or metadata labels.
- [ ] No clipped words or missing line endings.
- [ ] Consistent loudness between segments.
- [ ] Narration synchronizes with the scene action.
- [ ] Emotional lines are not overacted.
- [ ] Final audio has no clipping or distracting noise.

If a line sounds wrong, re-render with the same voice profile and adjust only supported delivery controls.
